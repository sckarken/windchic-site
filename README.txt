WINDCHIC — website v6 (November 2026)

STRUCTURE
- Static site for GitHub Pages (CNAME windchic.com, .nojekyll kept).
- English at the root, French in /fr/, Chinese in /zh/ — real pages, no client-side translation.
- All copy lives in tools/content.py (one entry = English, French, Chinese).
- Page templates live in tools/build.py. Never edit the generated .html files by hand.

GEO / SEO (visibility in search engines and AI assistants)
- Every page carries JSON-LD (Organization, WebSite, page type; services catalogue
  on home/services; FAQPage on faq.html). Generated in tools/build.py (jsonld()).
- faq.html in three languages: the page AI assistants quote most. Content in
  tools/content.py (FAQ list). Chinese questions are phrased the way people ask.
- robots.txt, llms.txt and llms-full.txt are generated by the build. Do not edit them.
- After each deploy: python3 tools/indexnow.py (notifies Bing / Copilot).
- To fill in when ready (tools/build.py): CN_NAME (Chinese brand name), SAME_AS
  (official profiles: WeChat official account, Xiaohongshu, LinkedIn, Zhihu).
- Full plan: tools/GEO-PLAN.md

BUILD
  python3 tools/build.py        # regenerates 21 pages + 404.html + sitemap.xml + robots.txt + llms*.txt
  python3 -m http.server 8765   # preview at http://localhost:8765
